# HR Headcount Analysis Dashboard

## Project Overview
The HR Headcount Analysis Dashboard is an interactive data visualization project designed to analyze employee headcount and workforce distribution across different departments, countries, business units, job titles, genders, and age groups.

This dashboard helps HR teams understand workforce trends and make data-driven decisions through clear and interactive visualizations.

## Dashboard Features
- **Total Employee Headcount:** Displays the total number of employees.
- **Gender Analysis:** Visualizes employee distribution by gender.
- **Age Group Analysis:** Shows employee headcount across different age groups.
- **Department Analysis:** Provides department-wise employee information.
- **Country Analysis:** Displays employee distribution across countries.
- **Business Unit Analysis:** Analyzes headcount across business units.
- **Job Title Analysis:** Shows employee distribution by job title.
- **Headcount Trend:** Tracks employee headcount over time.
- **Interactive Filters:** Allows users to filter data by date, department, country, and employee name.
- **Export Data:** Enables users to export dashboard data.

## Tools & Technologies
- Microsoft Power BI
- Data Visualization
- Data Analysis
- HR Analytics

## Key Insights
- Total workforce: 500 employees.
- Gender distribution: 46.6% female and 53.4% male.
- Employee headcount is analyzed across multiple countries and business units.
- The dashboard highlights workforce distribution by job title and age group.

## Project Objective
The main objective of this project is to transform HR data into meaningful insights that support workforce planning, employee distribution analysis, and HR decision-making.
